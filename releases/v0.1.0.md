# v0.1.0

Initial public release of `codex-desktop-history-restore`.

## What this release includes

- Added a dual-mode workflow:
  - `handoff` for quickly continuing work in a new session
  - `restore` for repairing Codex Desktop local history and original-thread recovery
- Added auth-aware provider rules:
  - `chatgpt` mode should restore active threads to built-in `openai`
  - `apikey` mode can use a registered custom provider when appropriate
- Added safer restore guidance:
  - minimal backups by default
  - no backup for read-only handoff flows
  - cleanup guidance for redundant restore backups
- Added operator guidance for sharing, maintenance, and recovery checks
- Added bilingual README entry points for public distribution

## Why this exists

This skill is built for people who use Codex Desktop heavily and do not want work to stop when they:

- lose visible sidebar history
- switch between subscription accounts
- move from subscription mode to API mode
- need to continue work in a fresh session without losing context

## Included in this release

- public repo structure
- install script
- validation script
- skill instructions
- OpenAI agent config
- operator playbook reference
